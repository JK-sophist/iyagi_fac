# Design System

## 톤
- 다크 기반 생산성 SaaS
- 정보 밀도 높은 카드 대시보드

## 토큰
- radius: 16~24px (`rounded-2xl`, `rounded-3xl`)
- 상태 색상
  - danger: red
  - warning: amber
  - stable: slate
  - positive: emerald
  - checkpoint/branch: indigo

## 접근성
- 버튼/링크 focus ring
- aria-label 제공
- loading/empty/error state 제공
