# Editing Scenarios

## settings edit after scene acceptance
- 1개 장면 실행 후 settings-change-preview 호출
- 과거 충돌 가능 경고 확인
- `future_only` 적용으로 이후 장면만 영향

## mid-story character introduction
- 미등장 캐릭터에 introduce-plan 저장
- planned_scene_no 기반 등장 시점 조정

## soft delete candidate
- soft delete 후보 캐릭터 archive
- 이후 candidate participant selection에서 제외
