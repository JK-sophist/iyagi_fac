# Editing Rules

| 항목 | 즉시 반영 | 이후 반영 | 분기 권장 | 경고 필요 |
|---|---|---|---|---|
| 이름 변경 | - | ✅ | - | ✅ (기존 장면 표기 불일치 안내) |
| 성격 변경 | - | ✅ | ✅ (큰 톤 변화 시) | ✅ |
| 비밀 추가 | ✅ (미노출 상태 등록) | ✅ (노출 시점은 이후) | - | ✅ |
| 인물 추가 | ✅ (is_introduced=false) | ✅ (소개 장면부터) | - | - |
| 인물 soft delete | ✅ (`is_archived=true`) | ✅ (이후 장면 비활성) | ✅ (핵심 인물 제거 시) | ✅ |
| 세계관 룰 변경 | - | ✅ (`effective_from_scene_no`) | ✅ (기존 톤 보존 필요 시) | ✅ |
| 결말 목표 변경 | - | ✅ (`effective_from_scene_no`) | ✅ (내러티브 방향 전환) | ✅ |

## 원칙

- 과거 `scenes`는 수정하지 않음(immutable)
- 큰 변경은 `story_checkpoints` 기반 분기 세션 생성을 우선
