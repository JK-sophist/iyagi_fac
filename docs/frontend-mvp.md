# Frontend MVP

Next.js App Router 기반의 **개인용 작가 워크벤치** UX MVP.

## 포함 페이지
- 랜딩
- 프로젝트 목록/생성/상세
- 캐릭터 편집(목표 중심 입력)
- 관계도 편집(확장 관계 축)
- 세션 시작/진행(후보 생성/실행 + 직접 장면 목표 입력)
- 장면 상세(목표 충돌/계략 가능성 + 상태/작가 메모)
- 체크포인트/분기
- 작가 자유 메모

## 핵심 원칙
- 자동 결말/자동 챕터 없음
- 장면 실행 후 사용자 선택 대기
- 후보 생성은 목표 충돌 정보 중심
- 체크포인트/분기로 안전한 실험 지원

## Codex 추가 지시 없이 가능한 범위
- 프로젝트 생성
- 캐릭터 목표 입력/수정
- 관계 입력
- 세션 시작/후보 생성/장면 실행
- 장면 상태/작가 메모 저장
- 체크포인트/복원/분기
- 자유 메모 저장
- Markdown/TXT export 호출
