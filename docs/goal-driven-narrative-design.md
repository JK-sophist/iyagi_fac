# Goal-driven Narrative Design

## 왜 성향만으로는 부족한가
성향(archetype)만으로 장면을 만들면 캐릭터가 왜 지금 행동하는지 약해진다. 개인용 작가 워크벤치에서는 **목표(goal)와 충돌(conflict)** 이 장면을 구동해야 한다.

## 핵심 목표 모델
각 인물은 최소 아래 정보를 가진다.
- `surface_goal`: 겉으로 드러난 목표
- `hidden_goal`: 실제 목표
- `short_term_goal`: 현재 단계 목표
- `long_term_goal`: 장기 목표
- `fear_or_taboo`: 두려움/금기
- `leverage`: 타인을 움직이는 수단
- `secret`: 숨긴 정보
- `speaking_style_note`, `writer_note`: 작가 메모

## 목표 충돌 기반 장면 생성 원칙
후보 장면은 다음을 반드시 포함한다.
1. 누가 무엇을 원하나 (`active_motives`)
2. 누구와 충돌하나 (`goal_conflicts`)
3. 어떤 계략/협상/은폐/유혹이 가능한가 (`scheme_opportunities`)
4. 왜 지금 충돌이 발생하는가 (`why_now`)
5. 감정 변화보다 목표/관계/비밀 변화 중심의 `predicted_effects`

## 관계 확장 축
기존 신뢰/적대 외에 아래 축을 사용한다.
- `dependency`, `utility_value`, `surveillance_level`, `betrayal_risk`, `shared_secret`

## 결말 벡터 개념
단일 엔딩 대신 방향 벡터를 쓴다.
- `collapse_vector`
- `domination_vector`
- `reconciliation_vector`
- `betrayal_vector`
- `corruption_vector`

이 벡터는 세계/엔딩 설정 변경과 scene 누적 결과를 해석하는 축으로 사용한다.
