# UX Principles

## 디자인 톤

- 작가용 워크벤치 / 실험실 / 운영 대시보드 느낌
- 차분하고 전문적인 생산성 도구 인상
- 데스크톱 우선

## 레이아웃

- 카드 기반 2단 구조
- 좌측: 설정/상태/관계
- 우측: 현재 작업 패널
- 상단 헤더 + 좌측 사이드바 + 메인 패널

## 다크 테마 토큰

- 배경: slate/zinc 계열
- 강조: indigo/cyan
- 경고/위험: amber/red
- 성공: emerald

## 필수 플로우

`후보 제안 -> 사용자 선택 -> 장면 실행 -> 상태 변화 확인 -> 사용자 승인`

장면 실행 직후 자동으로 다음 장면으로 넘어가면 안 된다.
